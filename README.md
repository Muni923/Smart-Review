## Features

* AI-powered code reviews
* Supports 10+ programming languages
* JWT-based authentication
* Submit source code for review
* AI-generated code improvement suggestions

## How It Works

1. User logs in securely using JWT authentication.
2. User selects a programming language and submits code.
3. The backend authenticates the request and sends the code to the AI model.
4. The AI analyzes the code and generates a review.
5. The review is displayed on the frontend.

## Tech Stack

* **Frontend:** React, Vite, Axios
* **Backend:** Node.js, Express.js, MongoDB, JWT, bcrypt
* **AI:** Gemini API
* **Deployment:** Vercel, Render, MongoDB Atlas
